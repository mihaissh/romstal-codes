# Romstal Companion (Product Search App)

A web application designed to help search and manage Romstal products, calculate change, add notes, and scan barcodes.

## Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Icons:** Lucide React
- **Backend/Database:** Supabase
- **Testing:** Vitest + React Testing Library
- **Other Tools:** html5-qrcode (Barcode scanning)
